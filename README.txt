Description: This app is intended to track both clients and work sessions through the use of databases, treeviews, pandas, and numpy.
To use the app first run the Database creator.py to use the base database that i made for the program with clients from the 
Metal Gear Solid series as test subjects or modify the lists with your own data to make your own databases. Next you can navigate
to the "Client_management.py" file to mess around with adding any additional clients or "work_sessions_logger.py" to log the sessions
of the clients to track how much you need to pay them. If you'd like to view all of the sessions in the database you can run 
"Session_list_viewer.py" which shows you all of the logged hour in the database and which client each entry belongs to. 
After checking all sessions and adding any additional clients or sessions you can view the "pay_summary_panel" which shows a break down of 
how much each client will be recieving when the payday occurs next and after you can run the "invoice_generator.py" to generate
an invoice for the pay period for your convinence!

Instructions:
1. Run the "Database creator.py" to create a default database or modify the lists in the code to mirror your own clients and sessions
2. Add any additional sessions or clients you'd like through "work_session_logger.py" or "client_management.py"
3. View the sessions being held in the database by running the "session_list_view.py" and filter by client through selecting in the dropbox and filtering
4. Create a summary for the payments for each of the clients and the totals for each "pay_summary_panel.py"
5. Create an invoice for the pay period from the sessions and client information "invoice_generators.py"
